# Chess Game Project

A Python-based chess game using Pygame and python-chess.

## Features
- Player vs Player
- Player vs Computer using Stockfish
- Casual Game and Analysis Game
- White and Black player selection
- Basic and Increment clocks
- Pause and Resume
- Undo and Redo in Analysis mode
- Check and Checkmate notifications
- Stalemate detection
- Resignation option
- Automatic Queen promotion

## Installation
pip install -r requirements.txt

## Run
python main.py
